---
id: SW-009
title: Access to an application the caller does not have
path: software
privileged: true
---
Granting access is privileged and additionally requires the caller's manager to be
named on the request.

1. Identify the exact application and the access level being asked for.
2. Confirm the caller's manager from the directory - do not accept a manager name given
   by the caller over the phone.
3. Raise an approval for `access.grant` including application, level and manager.
4. Tell the caller approval routes through their manager and IT, so it is not immediate.

An access request is never urgent enough to bypass approval, however the call goes.
