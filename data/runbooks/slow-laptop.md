Vague by nature; narrow it before acting.

1. Ask when it started and whether it is slow at all times or only in one application.
   One application is a software problem, not a hardware one.
2. Check uptime - anything over about two weeks without a restart is worth restarting
   first, and often ends the call.
3. Have them open Task Manager and read out the top process by CPU and by memory.
4. If a single process dominates, address that application. If nothing does and it is
   still slow after a restart, file a ticket for Field Services with the readings.

Do not recommend reinstalling the operating system. That decision is not the agent's.
